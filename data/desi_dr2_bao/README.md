# DESI DR2 BAO Data Provenance

This directory vendors the DESI DR2 BAO Gaussian mean/covariance files used by our local likelihood implementation.

- Official DESI data portal page (DR2 BAO cosmology results):
  https://data.desi.lbl.gov/public/papers/y3/bao-cosmo-params/README.html
- That page explicitly points to public likelihood files in:
  https://github.com/CobayaSampler/bao_data/tree/master/desi_bao_dr2
- Upstream source used here: `CobayaSampler/bao_data` tag `v2.6`
- Retrieval date (UTC): `2026-02-12`

Included files are mirrored from `bao_data/desi_bao_dr2/` and contain Gaussian BAO means and covariance matrices for DR2 subsets (including the combined `ALL` set).

Numeric content here is mirrored from `bao_data`, which the DESI data portal references for public DR2 BAO likelihoods.
